# Store掲載情報の草案と公開チェック

正式な製品名、発行者表示名、問い合わせ先はPartner Center登録後に確定する。この文書をそのまま公開せず、実際の審査項目に合わせて確認する。

## 説明案

### 短い説明

リンクを開くたびに、Edge・Chrome・Firefoxのブラウザープロファイルを選択できます。

### 詳細説明

仕事用、個人用など、複数のブラウザープロファイルを使い分けるためのWindows向けランチャーです。HTTP/HTTPSリンクを開く前にURLを確認し、使いたいプロファイルを選べます。

- インストール済みのEdge・Chrome・Firefoxのプロファイルを検出
- お気に入り、表示名、メモ、順序を設定
- ダブルクリックやキーボードで選択、既定ルールによる自動起動
- 日本語表示とWindowsの表示倍率に対応
- 設定は端末内に保存し、URLパターンの記録は既定でOFF

ブラウザー本体と利用するプロファイルは、あらかじめPCへ用意してください。インストールだけでは既定のブラウザーは変更しません。Windowsの既定のアプリ設定で、HTTP/HTTPSの候補としてHttpSelectorを選ぶと利用できます。ブラウザーのログイン状態やCookieはそれぞれのブラウザーが管理します。

## 公開前の確認

- [ ] 個人Partner Center登録、アプリ名予約、正式Identityの取得
- [ ] 発行者表示名と公開情報に意図しない個人名・住所等がないか確認
- [ ] ブランド用サポート窓口、サポートURL、プライバシーポリシー公開URL
- [ ] プライバシーポリシー案の確定と実装との一致
- [ ] 製品名、カテゴリ、価格、対象市場、年齢区分などの入力
- [ ] 依存ライブラリ・Rust/ネイティブランタイムのライセンス表示と配布条件の確認
- [ ] 選択画面、設定画面、既定のアプリ設定のスクリーンショット（サンプルデータのみ）
- [ ] スクリーンショットに実名・組織名・実URL・Windowsユーザー名が写っていないこと
- [ ] ブランド用ロゴ・掲載画像の確定（現在のパッケージ画像は開発用の暫定デザイン）
- [ ] runFullTrustの利用理由を審査メモへ記載
- [ ] Windows 10/11の対象ビルド、100〜200%表示倍率、標準ユーザーでの受け入れ検証
- [ ] MSIX版の初回起動、プロファイル検出、保存、ブラウザー起動、二重起動URL転送
- [ ] HTTP/HTTPS候補登録、引用付きURLの原文維持、既定値の不意な変更がないこと
- [ ] 同一Identityの更新で設定を維持、アンインストール時のデータと関連付け確認
- [ ] 非MSIX版・開発版からのデータ移行が必要か判断（現状は自動移行なし）
- [ ] Windows App Certification Kitと正式署名済み経路による検証
- [ ] stable MSIXの生成・検証とPartner Centerのパッケージ検証
- [ ] 審査結果に応じた修正、公開タイミングの決定

実機確認が終わっていない項目や、利用者が確定する公開情報はチェック済みにしない。Storeへの提出と公開は別の操作として実施する。
