## 作業方針

- 現行0.0.3.7に対する次の作業版を0.0.3.8として記録する。版付き配布物の作成と公開は別途指示時に行う。
- ESCの0は、長押しせず1回の押下で終了する意味として扱う。既存の有効な保存値は維持し、新規/設定欠落時の既定だけ0へ変更する。
- ドメイン保存は確認フォームを展開せず使える保存専用操作を追加する。保存だけではURLを開かず、従来の「開く」「戻る」を維持する。
- 入れ子URLを扱う既存の安全ガード、Shiftによる既存条件保持、Quad9の明示的な任意送信は維持する。
- 全画面のスクロールを標準サイズで不要にする。大量のプロファイル一覧内のスクロールは維持し、小さい画面では項目を隠さない退避を行う。
- READMEのユーザー編集、削除済みテンプレート、research/gomi.mdなど今回と無関係な変更は保持する。
