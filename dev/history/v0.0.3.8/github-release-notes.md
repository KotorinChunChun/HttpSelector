# HttpSelector v0.0.3.8（署名付きMSIX・ベータ版）

表示・MSIX・App Installerのバージョンはすべて **0.0.3.8** です。

## 変更内容

- Edge・Chromeのゲストモードに対応しました。通常のログイン済みプロファイルと分けて開きます。組織ポリシーでゲストが禁止されている場合は利用しません。
- 確認フォームを展開せず「ドメインを保存」できるようにしました。保存だけではURLを開きません。Shiftで既存登録を選び直した場合は「登録先を保存」となり、既存条件を保持します。
- ESC終了時間の未設定時の既定を0秒にし、1回の押下で終了できるようにしました。既存の有効な保存値は維持します。
- 「既定ルール一覧」をメイン画面の「設定」の右へ移し、お気に入り先頭に「既定」を表示します。「既定のアプリ設定を開く」の幅も調整しました。
- 設定画面の「保存」「キャンセル」を廃止し、プロファイル項目と全体設定を自動保存します。文字入力は入力を止めて約0.5秒後・フォーカス移動時・閉じる前、チェックと並べ替えは操作時に反映します。保存に失敗した場合は画面を閉じずに理由を表示します。
- 「下へ」の右へ「試しに開く」を追加しました。選択したプロファイルで空白ページを開きます。
- 設定効果のツールチップを追加し、長い説明文を整理しました。標準サイズで設定画面全体のスクロールを不要にしています。小さい画面では項目を隠さずスクロールへ切り替えます。

Quad9照会は既定OFFです。利用する場合だけ設定で明示的にONにしてください。この操作で自動保存します。送信するのはドメイン名とDNS問い合わせに必要な情報だけで、元URLのパス・パラメーターは送りません。送信先には接続元IP等が伝わります。OFFでも端末内の検査は継続します。
