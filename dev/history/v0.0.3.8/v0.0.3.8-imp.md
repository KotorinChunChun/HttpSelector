# HttpSelector v0.0.3.8 実装計画・報告

作成日: 2026-10-24 / main / [要求](v0.0.3.8-req.md)。事前調査・一部仕様確認中。

## 0. 事前確認

既存実装ではChromiumの保存プロファイルしか探索せず、起動時も一律にprofile-directoryを指定する。ゲスト専用の識別子と起動引数を設ける必要がある。

ESC設定の既定は10（1.0秒）、最小は1（0.1秒）。入力検証・ストレージ・起動時クランプ・タイマーが同じ制約を使うため、すべての境界を揃える。

設定画面は編集結果を閉じた後でmainへ返す方式。状態変更時の永続化コールバックと、失敗時に未保存と分かる表示を導入する。既存の署名付きバックアップとトランザクションを維持し、一般設定の即時保存範囲はQA回答に従う。

SettingsLayoutは多数の説明ラベルを縦へ積み、名称承認解除をさらに下へ追加している。説明をツールチップへ移し、プロファイル一覧・編集と全体設定をコンパクトに並べる。ウィンドウ全体のスクロールを通常表示で不要にし、必要時は既存のPageへ退避する。

## 3. 影響範囲と境界

Rust/Win32の独立子Gitを維持。親の.NET用BrandedForm等はこのRust製品へ直接適用しない。タイトル/アイコンは既存共通実装を利用する。対象外の実ユーザーDB、認証URL、ブラウザーCookie、証明書ストアに触れない。実ブラウザーのゲスト/試し起動を検証する場合は無通信の空ページで行い、UI試験は隔離サンプルを使う。

## 4. 追加対応・QA

QA回答後に記録する。ゲストを禁止する組織ポリシーを回避する処理は追加しない。
