# HttpSelector v0.0.3.2 要求

他バージョンの実装中は本書を読まず、要求を取り込まないこと。

## 未実装

1. 高リスクurlを検知して開く前に警告して欲しい。
2. ローカル判定と外部照会を併用し、外部へはサブドメインを含むドメインのみ送信する。
3. 全角アルファベットや大手サービスの誤字を狙った攻撃のパターンマッチングを行う。
4. 警告にアクセス先と判定理由を表示し、「キャンセル」を初期選択、「それでも開く」を明示的に選んだ場合だけ開く。ルール一致・割り込みオフにも適用する。
5. 外部照会はQuad9を利用し、通信失敗時は確認不能として警告する。
6. 初期の照合対象をGoogle・Microsoft・Apple・Amazon・PayPal・LINE・Yahoo! JAPAN・楽天とする。
7. 表示バージョンとMSIXバージョンの数値部分を0.0.3.2に揃える。
8. 完了後、チャット「全体」（01a1252f-e87f-7053-ac66-a6d0521e48b6）を参照し、独立Gitを保持してKotorinToysの管理下へ移動・登録する。
9. その後リファクタリングとドキュメントを更新する。
10. 本ツールは関連付け登録のため署名付きMSIXからのインストールを必須とし、MSIX導入を推奨する手順にする。KotorinToysも登録済みMSIXを管理対象とする。
