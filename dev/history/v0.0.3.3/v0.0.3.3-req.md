## 実装済

要求1〜12は完了。共通フォームの実操作プレビュー、署名付きMSIXの生成・公開とHTTPS検証を確認。[実装報告](v0.0.3.3-imp.md)を参照。当初は実装のみの範囲とし、その後の追加指示で要求12のMSIX作成・公開を行った。インストールは今回の追加指示に含めない。

1. 毎回のドメイン連携Yes/Noを独自フォームへ置き換える。見出しは「以下のURLをChrome / 個人 で開く」のように選択プロファイルを表示する。
2. 通常はURL・「開く」「戻る」・折りたたまれた「今後の動作を設定」を表示する。戻る・Esc・閉じるはURLを開かずプロファイル選択へ戻る。
3. 設定を開くとURLのドメイン・スラッシュ区切りのパスを個別ボタンで選べる。ONの部分だけ固定し、既定はドメインだけON。
4. クエリパラメータも名前と値の組で個別選択できる。既定はすべてOFF。パラメータの先頭に「?」を表示し、「名前=値」のイコール直後に強制改行しない。多数のパラメータ・長いMicrosoft 365 URLに対応する。
5. HTTP・HTTPS共通、フラグメントは判定対象外とする。選択済みクエリは順不同で全項目の一致を必要とし、未選択のクエリは任意。
6. 「次回から選択プロファイルで自動的に開く」「今後、関連付けを質問しない」を選べる。質問省略はプロファイル選択と高リスクURL警告を省略しない。
7. 生成する正規表現を表示・コピー可能にし、保存済みの同じ式で実行時も照合する。選択状態を保存し、既存ワイルドカードルールを維持する。
8. 「保存」は設定だけを保存して折りたたみを閉じる。URLを起動せず、利用者がその後「開く」か「戻る」を選ぶ。保存した内容は戻っても有効。
9. 不要なON/OFF説明、固定動作のラベル、日本語の対象範囲要約、動作選択の見出し、サンプル用注記を製品画面へ入れない。
10. 実装・テスト・リファクタリング・利用資料更新を行う。表示版とMSIX生成設定の数値は揃える。今回の指示は実装であり、インストール・外部公開は含めない。
11. ボタンのデザインを揃える（2026-10-17追加）。URLのドメイン・パス・クエリ選択ボタンを「開く」「保存」と共通の角丸・枠線へ統一し、ONを識別できる配色にする。
12. v0.0.3.3の署名付きMSIXを作成して公開する。表示バージョンとMSIXバージョンの数値は揃える（2026-10-17追加）。

| --- | --- |
