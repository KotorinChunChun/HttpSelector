## v0.0.1 の補足仕様

- 対応 URL は `http://` と `https://` のみとし、その他はエラー表示して開かない。
- デコード結果は表示専用とし、ブラウザへ渡すURLは受け取った元URLを維持する。
- 通常タイルは、有効かつお気に入りでないプロファイルをユーザー指定順で上位20件表示する。
- 25件を超える項目は設定画面から有効状態や並び順を変更する。
- 独立起動アプリのため「モーダル」は、単一起動・最前面・選択または長押し終了まで常駐する動作として扱う。
- ブラウザ実行ファイルパスはDBへ保存せず、起動の都度既知のレジストリおよびインストール先から解決する。
- Firefoxの既存プロセスによるプロファイル選択差異は、実機テスト結果を文書化する。
