### 公開・匿名再取得

[GitHub Release v0.0.3.9](https://github.com/KotorinChunChun/HttpSelector/releases/tag/v0.0.3.9)はRelease ID 422807038、draft=false、prerelease=falseでlatestに指定。ベータ版の位置付けは名称と本文に明記した。4アセットを認証なしでGETし、長さ・SHA-256がすべてローカルと一致した。API登録MIMEは正しく設定したが、匿名配信はapplication/octet-streamのため、App Installerの更新先は既存公開サイトを維持する。

[公開サイト](https://excel-chunchun.sakura.ne.jp/download/HttpSelector.html)は対象6ファイルだけFTPS配備し、公開前退避は `logs/publish-20261024T151501Z-7ab511ce/`。7 URLのHTTPS応答・MIME・内容を検証した。MSIX/CER/App Installerをさらに認証なしでGETし、GitHub側と同一のバイト列であること、App Installerのルート版・MainPackage版・参照URLが0.0.3.9で一致することを確認した。共有メニュー・他製品はアップロードしていない。

サイト独立Gitは `cb03234d3795671505dd0194686a00384d8c89e4` で対象3変更だけコミットした。既存のScriptSyncコミットが未pushだったため、ローカルoriginへのpushは混ぜずに保持した。FTPSによるHttpSelectorの公開と再取得検証は完了している。
