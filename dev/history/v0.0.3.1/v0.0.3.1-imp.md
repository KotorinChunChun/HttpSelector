## 0. 事前確認

- 現行のお気に入りは選択画面の「↑」「↓」と設定画面で変更できる。上限5件。
- 手動更新は変化の有無に関係なく結果をダイアログ表示する。
- URLに一致する既定ルールは画面前に適用される。未一致は選択画面へ進む。
- ドメイン案内は開く操作の直前に表示し、「はい」で同一ホストのHTTP/HTTPSルールを保存する。案内頻度についてユーザー回答は未着のため暫定仕様。
- 割り込みオフで利用可能なお気に入りがない場合は、操作不能を避けるため選択画面に戻す暫定仕様。ユーザー回答は未着。

## 2. 要件別方針

1. 一覧の右上に選択中プロファイルのピン操作を設け、既存の上限とDB保存経路を使う。
2. URLを開くプロファイルが確定したときにドメイン連携を案内し、回答に従い既定ルールを保存する。
3. 選択画面のボタン文言を変更する。
4. 再探索結果に差分がある場合のみ通知する。
5. トグル値を既存 Settings テーブルに保存し、URL受信時のルーティングに反映する。
6. 指定ラベルを画面から除き、レイアウトを調整する。

## 3. 影響範囲

選択画面、起動経路、既定ルール、設定DB、利用者ガイド、版番号。

## 4. 実装で判明した追加対応

- トグル追加で広い画面のタイトルとボタンが重なったため、ヘッダー幅と狭い画面での折り返し位置を修正した。
- CargoのSemVerは4桁を受け付けないためパッケージ版を `0.0.3+1`、画面表示を `0.0.3.1` とした。MSIXの現行配布設定は公開済み `0.0.3.0` のまま。既存のMSIX規約では4桁目が0なので、この版を配布するときは新しいパッケージ版の決定が必要。
- `final-test-recorder` は利用したが、録画対象の前面化に失敗し、画面全体録画も `gdigrab` の `Failed to capture image (error 5)` で停止した。ログは `logs/recording-1e4f02c1e4054b9db4e7f8a1cb672d33/` に保存した。
