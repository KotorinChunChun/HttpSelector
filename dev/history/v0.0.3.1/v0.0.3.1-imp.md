# HttpSelector v0.0.3.1 実装計画・報告

対応要件: [v0.0.3.1-req.md](./v0.0.3.1-req.md)  
作成日: 2026-09-27 / 状態: 実装中

## 0. 事前確認

- 現行のお気に入りは選択画面の「↑」「↓」と設定画面で変更できる。上限5件。
- 手動更新は変化の有無に関係なく結果をダイアログ表示する。
- URLに一致する既定ルールは画面前に適用される。未一致は選択画面へ進む。
- ドメイン案内とお気に入り不在時の動作はユーザー回答待ち。

## 1. 実装順序とコミット単位

| 順 | 内容 | 主な対象 |
| :--- | :--- | :--- |
| 1 | 表示文言、更新通知、ピン操作 | `src/ui.rs`, `src/ui_layout.rs`, `src/main.rs` |
| 2 | ドメイン連携案内とルール保存 | `src/main.rs`, `src/storage.rs`, `src/url_pattern.rs` |

## 2. 要件別方針

1. 一覧の右上に選択中プロファイルのピン操作を設け、既存の上限とDB保存経路を使う。
2. URLを開くプロファイルが確定したときにドメイン連携を案内し、回答に従い既定ルールを保存する。
3. 選択画面のボタン文言を変更する。
4. 再探索結果に差分がある場合のみ通知する。
5. トグル値を既存 Settings テーブルに保存し、URL受信時のルーティングに反映する。
6. 指定ラベルを画面から除き、レイアウトを調整する。

## 3. 影響範囲

選択画面、起動経路、既定ルール、設定DB、利用者ガイド、版番号。
