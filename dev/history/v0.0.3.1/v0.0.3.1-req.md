## 実装済

実装内容と検証状況: [v0.0.3.1-imp.md](./v0.0.3.1-imp.md)

1. プロファイルのお気に入り登録ができない？プロファイル一覧の画面右上にピン止めを置いて簡単に登録したい。
2. プロファイルを選択したとき、このドメインを連携させるか案内を表示する。
3. 右上のWindowsの設定を開くのボタンのキャプションは既定のアプリ設定を開くに変える。でアプリの設定を開くボタンのキャプションは設定に変える。
4. 更新ボタンを押せるキー。変更はありませんというダイアログが出るが、出さなくていいです。
5. アプリの設定を開くのボタンの左に割り込みを有効にするというトグルを設置してください。このトグルがオンのときは現在のようにURLを開くときに割り込みを行います。オフのときはルールに該当した場合はそのプロファイルで開くんですけど、該当するルールがなかった場合のURLは自動的にお気に入り1のプロファイルで開くようになってください。このアプリの画面を出さないでください。
6. リンクを開くプロファイルは選択とダブルクリックで開くというラベルは削除してください。
