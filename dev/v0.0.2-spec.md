# HttpSelector 設計書 v0.0.2

## v0.0.2で追加する設計

- 保存済み一覧を先に表示し、初回以外の起動後にバックグラウンドでプロファイルを1回探索する。
- 追加、変更、再検出、未検出に差分がある場合だけSQLiteと完全性署名を更新する。
- 選択画面の既定プロファイル設定ボタンの左に、同じ差分同期を手動実行する「更新」を配置する。
- アプリ版は0.0.2、公開Beta MSIXは0.0.2.0とする。公開済み1.0.3.0からの番号リセットのため、既存Betaはアンインストール後に新規導入する。

## 1. 概要

HttpSelector は Windows の http / https プロトコル関連付けを置き換え、リンククリック時にユーザーがブラウザプロファイルを選択してから URL を開くためのユーティリティである。

本製品はブラウザ選択ツールではなく、複数アカウント・複数テナント・複数用途を使い分けるユーザー向けのブラウザプロファイル選択ランチャーとして設計する。

---

## 2. 開発目標

### 主目的

ユーザーがリンクを開く際に

- 個人アカウント
- 会社アカウント
- 開発用アカウント
- テスト用アカウント

などを意図的に選択できるようにする。

### 品質目標

- 高速起動
- シンプルな操作
- 安全な設定管理
- URL履歴を既定で残さない
- キーボードだけでも操作可能

## 4. 動作概要

### 基本フロー

```text
URLクリック
    ↓
HttpSelector起動
    ↓
URL表示
    ↓
プロファイル選択
    ↓
対象ブラウザ起動
    ↓
URLオープン
```

### キャンセル時

```text
URLクリック
    ↓
HttpSelector起動
    ↓
ユーザーキャンセル
    ↓
何も開かない
```

## 27. セキュリティ設計

### 目的

### 方針

---

## 28. 改ざん検知

保存時

```text
SQLite
↓
HMAC-SHA256生成
↓
署名保存
```

起動時

```text
SQLite読込
↓
HMAC再計算
↓
署名検証
```

---

## 29. 鍵管理

秘密鍵は平文保存しない。

Windows DPAPI を利用する。

### 保存方式

```text
ProtectedData.Protect()
```

### 復号

```text
ProtectedData.Unprotect()
```

### スコープ

```text
CurrentUser
```

---

## 30. 改ざん検出時

表示

```text
設定ファイルが変更または破損しています
```

### 選択肢

- 復旧
- 初期化
- 終了

---

## 31. 起動コマンド保護

設定にはブラウザ実行ファイルパスを保存しない。

### 保存対象

```text
BrowserType
```

のみ。

### 例

```text
1 = Edge
2 = Chrome
3 = Firefox
```

ブラウザ実行ファイルは内部ロジックで解決する。

これにより設定改ざんによる不正実行を防止する。
