# HttpSelector 設計書 v0.0.3

## 1. ブラウザの前面表示

- ブラウザ起動前後のトップレベルウィンドウを取得し、選択したブラウザの実行ファイルに属するウィンドウを識別する。
- 新規に作成されたウィンドウを優先し、既存ブラウザへURLが渡された場合は対象ブラウザ内で手前にあるウィンドウを候補とする。
- 対象ウィンドウが最小化されている場合は復元し、前面化を要求する。
- Windowsの起動処理は非同期であるため、短い間隔で上限時間付きの確認を行う。無制限の待機は行わない。
- URLを二重に開かないため、URLの起動に成功した後の前面化失敗をブラウザ起動失敗として再試行しない。
- `--new-window`やキー入力の疑似送信は使用せず、現在のタブ起動動作を維持する。

## 2. バージョン表示

- 表示する版は`Cargo.toml`のpackage versionをコンパイル時に取得し、画面ごとに重複してハードコードしない。
- メイン画面は、Win32ウィンドウ名と画面上部の見出しを`HttpSelector v0.0.3`形式にする。
- 設定画面は`HttpSelector v0.0.3 - 設定`、既定ルール画面は`HttpSelector v0.0.3 - 既定ルール`形式にする。
- 設定ファイルエラーなど、アプリ固有のダイアログにも同じ版表記を使用する。

## 3. 最大化の無効化

- 設定画面から`WS_MAXIMIZEBOX`を削除する。
- 各主要画面で`SC_MAXIMIZE`を拒否し、最大化ボタン、タイトルバーダブルクリック、ショートカット、スナップ操作からの最大化を防ぐ。
- 最大化だけを禁止し、通常のサイズ変更と最小化からの復元は維持する。

## 4. 確認対象

- Chrome、Edge、Firefoxが未起動、背面表示、最小化、複数プロファイル表示の各状態。
- プロファイルのクリック、ダブルクリック、Enter、既定ルールによる起動経路。
- メイン画面、設定画面、既定ルール画面の版表示と最大化禁止。
